# El Tontunario

This is the home page repository and podcast hosting for *El Tontunario*.
https://www.eltontunario.com

## Contributing

Clone this repository and ensure you meet the following requirements:

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) (v7 or higher)
- [bundle](https://bundler.io/) `gem install bundler -v "~> 2.5"`

## Adding posts

Add new posts in the `_posts` folder. Use the existing posts as a reference for the required front matter and structure.
